Get Started in 2 Minutes

Install, configure, and start sending emails — it's that simple.

# Install AgenticMail
npm install -g agenticmail

# Start the server
agenticmail start

# Set up Gmail relay (easiest)
agenticmail setup relay --provider gmail

# Or use as MCP server
agenticmail mcp --transport stdio

# Or as OpenClaw plugin
openclaw skill install agenticmail
